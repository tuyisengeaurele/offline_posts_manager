# offline_posts_manager

This app is called Offline Posts Manager. It uses Flutter for the UI and SQLite through the sqflite package for local data storage. The app allows users to add, read, update, and delete posts even without internet. I separated the code into model, database, screens, and widgets for clean architecture. I also handled database errors using try-catch and protected against invalid data when converting database rows into Post objects.
